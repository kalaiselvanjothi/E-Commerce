## 🐛 Reporting a Vulnerability

If you discover a security vulnerability within ShopVerse, please **do not** open a public GitHub issue. Instead:

1. Send an email directly to **support@shopverse.com** or **kalaiselvanjothi** on GitHub.
2. Include details about the vulnerability, steps to reproduce, and any proof-of-concept code.
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide an estimated timeline for remediation.
